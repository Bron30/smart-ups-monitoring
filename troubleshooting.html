🔧 UPS Troubleshooting Guide

Smart DC UPS Monitoring System

1. Quick Troubleshooting Reference

Problem Possible Cause Recommended Action
Dashboard shows no data ESP32 or Wi-Fi connection problem Check ESP32 power and Wi-Fi connection.

Battery percentage abnormal Incorrect voltage reading or battery condition Check battery voltage and sensor connection.

2. Dashboard Shows No Data

Possible Causes:
  • ESP32 is not powered.
  • ESP32 is not connected to Wi-Fi.
  • Firebase connection is unavailable.
  • Sensor data is not being transmitted.
Recommended Actions:
  1. Check ESP32 power supply.
  2. Check Wi-Fi availability.
  3. Check ESP32 serial monitor.
  4. Verify Firebase data.
  5. Check sensor connections.

3. Battery Voltage Not Displayed

Possible Causes:
  • Voltage sensor is disconnected.
  • Sensor wiring is incorrect.
  • ESP32 is not receiving the sensor value.
Recommended Actions:
  1. Check voltage sensor wiring.
  2. Check the sensor output.
  3. Verify the ESP32 input pin.
  4. Check the value stored in Firebase.

4. Battery Percentage Appears Incorrect

Possible Causes:
  • Incorrect battery voltage measurement.
  • Battery voltage-to-percentage mapping is inaccurate.
  • Battery condition has changed.
Recommended Actions:
  1. Verify the measured battery voltage.
  2. Check the battery percentage calculation.
  3. Compare the reading with a suitable multimeter measurement.

5. Temperature Reading is High

Possible Causes:
  • UPS is operating under high load.
  • Insufficient ventilation.
  • Ambient temperature is high.
  • Temperature sensor is positioned incorrectly.
Recommended Actions:
  1. Check the UPS load.
  2. Improve ventilation.
  3. Check the temperature sensor position.
  4. Allow the system to cool before further operation if necessary.

6. Vibration Detected

Possible Causes:
  • UPS enclosure is moving.
  • External mechanical vibration is present.
  • SW-420 vibration sensor is too sensitive.
Recommended Actions:
  1. Check the UPS mounting.
  2. Check nearby mechanical equipment.
  3. Verify the SW-420 sensor mounting.

7. UPS Status Shows FAULT

Possible Causes:
  • Battery voltage is outside the expected range.
  • Temperature is too high.
  • Abnormal current is detected.
  • Vibration condition is abnormal.
Recommended Actions:
  1. Check battery voltage.
  2. Check temperature.
  3. Check load current.
  4. Check vibration condition.
  5. Inspect the UPS if the fault persists.

8. Safety Precautions

  • Do not short-circuit the battery terminals.
  • Do not exceed the rated UPS load.
  • Disconnect power before modifying hardware connections.
  • Keep the UPS away from water and excessive heat.
  • If an electrical fault is suspected, stop operation and inspect the system safely.
