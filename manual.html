📖 Smart UPS User Manual

QR-Enabled Intelligent UPS Monitoring & Maintenance System

1. System Overview

The Smart UPS system combines a UPS power system, ESP32-based monitoring, electrical and thermal sensors, automatic load management, Firebase cloud storage and a QR-authenticated web dashboard.

System functions:
  • Real-time battery condition monitoring
  • Per-load current and power monitoring
  • Battery State of Charge (SoC) estimation
  • Automatic priority-based load shedding
  • UPS status and operating-mode indication
  • Event recording
  • QR-based authenticated access to digital monitoring, maintenance and documentation

2. System Architecture

Battery / UPS → Sensors → ESP32 → Wi-Fi → Firebase → QR-Authenticated Web Dashboard

Commercial concept: A commercial UPS installation may include rectifier, DC link, battery bank, inverter and static bypass. The physical student prototype is a scaled low-power demonstration and must not be treated as a mall-scale UPS.

3. Parameters Monitored

  • Battery Voltage: measured battery voltage.
  • Battery Current: battery charge/discharge current.
  • Battery Temperature: measured battery/system temperature.
  • Battery SoC: estimated state of charge; it is an estimate and is affected by load, temperature, battery age and operating condition.
  • Total Load Power: estimated/ measured combined load power.
  • Status: overall condition such as Healthy, Warning or Fault.
  • Mode: operating state such as NORMAL, LOAD_SHEDDING, CHARGING, RECOVERY or FAULT.
  • Timestamp: time associated with the latest telemetry record.

4. Per-Load Monitoring

The system can monitor four demonstration load channels.

  • CH1 – Critical: critical POS/networking type load; protected from ordinary SoC-based shedding.
  • CH2 – Medium priority: emergency lighting type load.
  • CH3 – Medium priority: motor/demo load; special attention is required for startup current.
  • CH4 – Non-critical: demonstration lamp; first load to be shed during low-SoC operation.

5. Automatic Load-Shedding Logic

Load shedding is based on battery SoC and protection conditions. Thresholds are intentionally separated to provide hysteresis.

  • Below 60% SoC: CH4 is shed.
  • Below 40% SoC: CH3 is shed.
  • Below 25% SoC: CH2 is shed.
  • CH1: retained during ordinary SoC-based shedding because it is classified as critical.
  • Overcurrent, severe temperature, sensor failure and battery-protection conditions can override normal load priorities.

Recovery: CH2 may restore at ≥35%, CH3 at ≥50% and CH4 at ≥70%, provided no fault condition exists.

6. Operating the Digital Dashboard

  1. Scan the QR code attached to the UPS.
  2. Open the displayed web address.
  3. Sign in using an authorized account.
  4. The gateway validates the UPS QR identifier and its active security status.
  5. After successful authentication, open the dashboard.
  6. View live SoC, battery voltage, load power, operating mode and UPS status.
  7. Open UPS Monitoring for detailed telemetry and per-channel information.
  8. Open Maintenance for service information and Documentation for the manual and troubleshooting guide.

7. Events and Maintenance

The system can record important events such as load-state changes, protection events, system initialization and other defined operating conditions. Maintenance information contains the last and next service dates configured for the UPS.

8. Network / Cloud Operation

  • The ESP32 performs local monitoring and protection logic.
  • Wi-Fi/Firebase is used for telemetry and dashboard visibility.
  • If Wi-Fi or Firebase becomes unavailable, local protection and load-control logic should continue to operate.
  • Cloud connectivity must not be treated as the primary safety mechanism.

9. Safety Precautions

Important: This is a prototype monitoring/control system. Never expose the ESP32, breadboard or low-voltage prototype wiring directly to hazardous mains voltage.
  • Use correct battery protection, fusing, isolation and an appropriate enclosure.
  • Do not short-circuit lithium-ion cells or battery terminals.
  • Use only correctly matched cells and a suitable BMS/charger for the battery configuration.
  • Do not exceed UPS, inverter, relay, sensor or wiring ratings.
  • Never route high-current battery or 230 V AC wiring through a breadboard.
  • Use properly isolated AC voltage/current sensing.
  • Disconnect power before hardware modification or maintenance.
  • Do not bypass BMS or other protection devices.
  • For commercial/high-power UPS installations, use qualified electrical personnel and appropriate protection procedures.

10. Recommended Demonstration Sequence

  1. Start with normal operation and verify all sensor readings.
  2. Demonstrate dashboard updates.
  3. Reduce simulated/actual SoC within safe limits and demonstrate CH4 shedding.
  4. Continue to the next thresholds to demonstrate CH3 and CH2 shedding.
  5. Show that the critical CH1 remains enabled under ordinary SoC shedding.
  6. Raise SoC and demonstrate staged recovery.
  7. Review the generated events on the dashboard.
