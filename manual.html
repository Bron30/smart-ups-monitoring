📖 Smart DC UPS User Manual

QR-Enabled Smart UPS Monitoring System

1. System Overview

The Smart DC UPS Monitoring System is designed to monitor the operational condition of a DC UPS and provide real-time information through an IoT-based monitoring system.

Monitoring Parameters:
  • Battery Voltage
  • Battery Percentage
  • Temperature
  • Load Current
  • Vibration
  • UPS Status

2. System Operation

The DC UPS supplies power to the connected DC load. The ESP32-based monitoring unit collects UPS operating parameters and sends the information to the Firebase Realtime Database through Wi-Fi.

Basic workflow:

DC UPS → Sensors → ESP32 → Wi-Fi → Firebase → Web Dashboard

3. Monitoring Dashboard

The dashboard provides real-time information about the UPS operating condition.

  • Battery Percentage: Displays the estimated battery charge level.
  • Battery Voltage: Displays the measured battery voltage.
  • Load Current: Displays the measured load current.
  • Temperature: Displays the measured temperature.
  • Vibration: Displays the detected vibration condition.
  • UPS Status: Displays the overall UPS condition.

4. QR Code Access

A QR code attached to the UPS provides quick access to the digital UPS monitoring and maintenance portal.

Procedure:
  1. Open the camera or QR scanner on your smartphone.
  2. Scan the QR code attached to the UPS.
  3. Open the displayed web link.
  4. Access the UPS monitoring dashboard.
  5. View maintenance and documentation information.

5. Maintenance

The digital maintenance section provides access to service information associated with the UPS.

  • Last Service Date
  • Next Service Date

Service information is retrieved from the cloud database associated with the UPS.

6. Basic Precautions

  • Ensure that the UPS connections are properly secured.
  • Do not short-circuit the battery terminals.
  • Keep the UPS and battery away from excessive heat and moisture.
  • Do not exceed the rated load of the UPS.
  • Disconnect power before performing hardware modifications or maintenance.
